# Power BI Dashboard

This folder contains information about the Power BI dashboard created for the CareFlow clinical pathway process mining.

## Dashboard visuals

Unique Patients: Number of unique patient case ID's

Total Events: Total number of events

Unique Activities: Number of unique activities.

Patients per Activity: Patients per activity.

Clinical Activity Frequency: Frequency of each activity.

Activity per Patient: Distribution of events between activities.

Clinical Activity over Time: Clinical events over time.

Clinical Events per month: Number of events per month.

## Data Source

The dashboard uses data from the raw_events table in Google BigQuery. This table contains case_id, activity and timestamp.

## Current Progress

The basic dashboard has been created. More validation and interpretation will be done with the results as the project continues.
